# DP Performance — GHL setup for Dan (do tonight)

Goal: connect **WhatsApp, Instagram and Facebook** to the DP Performance GoHighLevel
account so the Inbox and lead capture go live. **Connecting does NOT message anyone** —
every automation stays off. About 15–20 minutes.

## Before you start (5 min — this saves the headaches)
In ONE browser window:
1. Log into the **Facebook account that is an admin** of the DP Performance Facebook Page
   and Meta Business.
2. Make sure the DP **Instagram is a Professional (Business or Creator) account**, and that
   it is linked to that Facebook Page. (IG app → Settings → Account type.)
3. Have a **phone number for WhatsApp that is NOT currently signed into the WhatsApp or
   WhatsApp Business app.** If your business number is on WhatsApp right now, you'll need to
   delete that WhatsApp account first (WhatsApp → Settings → Account → Delete my account)
   or use a fresh number.

## Connect the channels — GHL → Settings → Integrations
1. **Facebook & Instagram** → Connect → log in with that Facebook account → select the DP
   Page (the one linked to Instagram) → allow **all** permissions → Connect → **Sync Leads**.
   Enable Instagram messaging when prompted.
2. **WhatsApp** → start the WhatsApp onboarding → log into **Meta Business** → follow the
   flow to create/confirm the WhatsApp Business profile → **verify the phone number** (code
   comes by SMS/call; if you use a LeadConnector number the code shows in Conversations).
   Note: once a number is registered for WhatsApp here it becomes WhatsApp-only (no normal
   SMS on that number).
3. (Optional, can wait) Email + SMS sending numbers — not needed for WhatsApp/IG, we'll set
   these up later.

## Calendar + Zoom (2 min)
My Profile (or Settings → My Staff → your profile) → Calendar / Conferencing → connect your
**Google/Outlook calendar** and connect **Zoom**. This lets discovery-call bookings sync.

## Send Kai these before you sleep (so he can finish the HQ)
- **Full names of every coach** + how many clients each can hold (**max capacity**).
- Confirm: is **"Schedule an Appointment"** the calendar new leads should book into? Which
  Zoom account?
- The **two marketing URLs** (booking page + thank-you page).
- The **team list for HQ logins**: name + role (coach / setter / closer / head coach) for
  everyone.

That's it — get this done and head to bed. Nothing here contacts a client; sends stay off
until we deliberately switch them on.
